# Uniswap integration feedback

AgentPermit Delta uses the V3 factory, pool, NonfungiblePositionManager and SwapRouter on an Ethereum mainnet fork. On 2026-09-13 the real SDK path passed mint, read, remove/collect, NFT burn and WETH sale for both fees 500 and 3000 at block 25965916. Each fee tier starts from the same snapshot; both finished with zero WETH residue. The repeated check was recorded locally at `2026-09-13T04:54:33.721Z` in `data/evidence/uniswap-fork-check.json`. The [reproducible check and assertions](scripts/check-fork.ts#L40) are public; local execution artifacts are not included in this documentation update.

1. The deployment pages and stable addresses made fork verification straightforward. We still resolve the pool from the factory and verify token order plus fee before every mint.
2. `NonfungiblePositionManager.addCallParameters` and `removeCallParameters` provide a compact, auditable path from onchain `slot0`/liquidity to calldata. A maintained TypeScript/viem example covering the full position lifecycle would reduce the adapter code needed to connect SDK outputs with contract reads and transactions.
3. During implementation, a newer SDK version pulled a large deprecated Hardhat/tooling dependency chain. We pinned `@uniswap/v3-sdk@3.8.3`; the production dependency audit performed on 2026-09-13 reported zero critical/high/moderate advisories and eight low transitive advisories. Keeping build tooling out of the runtime package would improve install size and dependency maintenance.
4. Fee accounting still requires a simulated `collect` to include uncollected fees in exposure. A documented read-only position-value/fee example for fork tests would make this easy to implement correctly.

Our first mixed-case USDC literal failed viem checksum validation. The corrected canonical address is `0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48`. Checking address literals and deployment bytecode before minting made that integration error observable; the read-only `npm run doctor` now verifies the configured archive block and actual local fork.

Reproduce with `npm run check:fork -- 25965916`; see [setup](docs/SETUP.md), [contract addresses and integration map](README.md#uniswap-integration), [SDK mint](server/uniswap.ts#L138), [fee reads](server/uniswap.ts#L153), and [remove/collect/burn/sale](server/uniswap.ts#L174). These are official-contract calls on a disposable local fork, not Ethereum mainnet receipts. Public-wallet UX, live mainnet gas and Hyperliquid execution are not established by this isolated run. This file accompanies the separate [Uniswap feedback form](https://developers.uniswap.org/hackathon-feedback); publishing it alone does not submit the form.
